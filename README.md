# Lucky Draw - The Matrix

## Mô tả Dự Án

Lucky Draw là một ứng dụng tương tác mô phỏng một buổi bốc thăm giữa các người tham gia. Ứng dụng được thiết kế để sử dụng trong bất kỳ sự kiện nào cần lựa chọn ngẫu nhiên, như rút thăm, cuộc thi hoặc các quy trình ra quyết định. Dự án sử dụng công nghệ web hiện đại để cung cấp trải nghiệm người dùng mượt mà.

### Chức Năng:
- **Giao diện thân thiện**: Điều khiển trực quan hướng dẫn người dùng qua quy trình bốc thăm.
- **Tùy biến**: Người dùng có thể nhập tên hoặc số tham gia.
- **Kết quả thực thời**: Ứng dụng nhanh chóng và hiệu quả, đảm bảo quy trình diễn ra suôn sẻ.
- **Khả năng truy cập**: Hệ thống được thiết kế cho nhiều thiết bị khác nhau, cho phép người tham gia tham gia từ điện thoại, máy tính bảng hoặc máy tính.

### Cài Đặt
Để chạy dự án này trên máy cục bộ:
1. Clone kho lưu trữ.
   ```bash
   git clone https://github.com/dongnnh2112work/Lucky-Draw---The-Matrix.git
   ```
2. Di chuyển vào thư mục dự án.
   ```bash
   cd Lucky-Draw---The-Matrix
   ```
3. Mở `index.html` trong trình duyệt.
