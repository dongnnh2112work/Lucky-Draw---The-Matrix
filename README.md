# Lucky Draw - The Matrix

## Project Description

Lucky Draw is an interactive application that simulates a draw among participants. It is designed to be used in any event where a random selection is required, such as raffles, competitions, or decision-making processes. The project leverages modern web technologies to provide a seamless user experience.

### Features:
- **User-friendly Interface**: Intuitive controls that guide users through the draw process.
- **Customization**: Users can input participants either as names or numbers.
- **Real-time Results**: The application generates results quickly and efficiently, ensuring a smooth flow without delay.
- **Accessibility**: The system is designed for a wide range of devices, allowing participants to join from phones, tablets, or desktops.

### Installation
To run this project locally:
1. Clone the repository.
   ```bash
   git clone https://github.com/dongnnh2112work/Lucky-Draw---The-Matrix.git
   ```
2. Navigate to the project directory.
   ```bash
   cd Lucky-Draw---The-Matrix
   ```
3. Open `index.html` in your browser.
